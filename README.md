# Claude for Safari

> **Unofficial.** This is a community project. It isn't made, endorsed or supported by Anthropic. Claude is a trademark of Anthropic.

A Safari extension that lets you use your own claude.ai account from any page. You don't need an API key and there's no extra billing. It works with the account you're already signed into in Safari.

- **Toolbar popup** (<kbd>⌥⇧C</kbd>): type a question, optionally attach the current page or your selection, and send it to Claude. Quick actions: *Summarize page*, *Key takeaways*, *Explain selection*, *Improve writing*.
- **Right-click menu**: *Explain with Claude* or *Ask Claude about "…"* on selected text, *Summarize Page with Claude*, and *Summarize Link with Claude*.
- **Shortcuts**: <kbd>⌥⇧S</kbd> summarizes the current page, and <kbd>⌥⇧N</kbd> opens a new Claude chat.
- **Settings**: open Claude in a new tab, in your existing Claude tab, or in a side window. You can also turn auto-send on or off, include the page by default, and set the page text limit.

When you ask something, the extension opens a new chat on claude.ai and fills in your prompt. If auto-send is on, it also sends it. Long pages are pasted the way claude.ai handles big pastes, so they show up as an attachment instead of filling the message box.

## Install (no Xcode needed)

Safari 18 and later can load an extension straight from this folder.

1. In Safari, open **Settings → Advanced** and turn on **Show features for web developers**.
2. Go to the new **Developer** tab and click **Add Temporary Extension…**.
3. Select the `extension` folder inside this project, then confirm with your password or Touch ID.
4. Click the Claude icon in the toolbar. When Safari asks, choose **Always Allow on This Website** for claude.ai. The extension needs this to type your prompt into Claude.
5. Make sure you're signed in at [claude.ai](https://claude.ai) in Safari.

> Temporary extensions are removed when Safari quits, so you'll need to repeat steps 2–3 after restarting Safari. To keep the extension installed, follow the next section.

## Install permanently (needs Xcode)

Safari only keeps extensions that come packaged inside a Mac app. Xcode is free from the App Store.

1. Install Xcode, open it once, then run:

   ```bash
   sudo xcode-select -s /Applications/Xcode.app
   ```

2. Generate the Xcode project from this folder:

   ```bash
   xcrun safari-web-extension-converter extension --macos-only --app-name "Claude for Safari" --bundle-identifier com.example.claude-for-safari --project-location app --copy-resources --no-open
   ```

3. Open `app/Claude for Safari/Claude for Safari.xcodeproj`. For both targets, go to **Signing & Capabilities**, set **Team** to your Apple ID (a free Personal Team works), and press <kbd>⌘R</kbd>.
4. In Safari, open **Settings → Extensions** and enable **Claude for Safari**.

If you skip signing, turn on **Allow unsigned extensions** in Safari's Developer settings. Safari turns that setting off every time it quits.

## Privacy

- The extension doesn't use any server of its own and doesn't call Anthropic's API. Your prompt goes only to claude.ai, in your own browser session.
- Page text is read only when you ask for it, through *This page*, a page action, or the right-click menu.
- The script that runs on claude.ai only fills in the message box. It reads nothing else there.

## Troubleshooting

- **The prompt didn't appear in Claude.** Check that the extension is allowed on claude.ai (Safari → Settings → Extensions → Claude for Safari → Edit Websites). If claude.ai changes its page layout, the extension shows a **Copy prompt** button so you can paste the prompt with <kbd>⌘V</kbd>.
- **"This page (link only)".** Safari doesn't let extensions read some pages, such as Safari's own pages, PDFs, or sites you haven't allowed. Claude gets the title and link instead.
- **Debugging.** With the extension loaded, use **Develop → Web Extension Background Content** for the background script. Right-click inside the popup and choose **Inspect Element** to inspect the popup.

```
  manifest.json            Manifest V3 for Safari
  background.js            Opens Claude and queues prompts; context menus and shortcuts
  content/claude-bridge.js Runs on claude.ai: fills in the composer and sends
  popup/                   Toolbar popup
  options/                 Settings page
  shared/                  Settings, page reading and prompt building; shared styles
  icons/                   Generated by tools/make-icons.swift
tools/make-icons.swift     Regenerates the icons: swift tools/make-icons.swift
```
